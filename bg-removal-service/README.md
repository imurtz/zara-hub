# خدمة إزالة خلفية الصور — Render

خدمة صغيرة تشغّل [rembg](https://github.com/danielgatis/rembg) (نموذج `u2net_human_seg`،
مخصص لصور الأشخاص) — مستضافة على [Render](https://render.com).

> **ملاحظة**: جُرِّب النشر على Google Cloud Run أولاً، لكن جوجل تتطلب موزّعاً محلياً معتمداً
> (CNTXT) للفوترة بعناوين السعودية — عملية تعاقد أطول من اللازم لهذا الاستخدام البسيط.
> Render تقبل أي بطاقة عالمية مباشرة بلا وسيط، فكانت الخيار الأعملي. الملفات نفسها
> (`Dockerfile`, `main.py`, `requirements.txt`) تعمل بلا أي تعديل — فقط طريقة النشر تغيّرت.

## خطوات النشر (كلها من المتصفح، بلا أي أداة تُثبَّت على جهازك)

1. اذهب إلى **render.com** وسجّل حساب (أسهل طريقة: زر "Sign up with GitHub" — يربط حسابك
   بمستودع الكود مباشرة).
2. من لوحة Render، اضغط **New +** ثم **Web Service**.
3. اختر **Build and deploy from a Git repository**، واربط حساب GitHub (لو أول مرة يطلب صلاحية
   وصول)، واختر مستودع **imurtz/zara-hub**.
4. بصفحة الإعدادات:
   - **Name**: `bawabat-zara-bg-removal` (أو أي اسم تحبه)
   - **Region**: اختر الأقرب جغرافياً (Frankfurt غالباً أقرب خيار متاح للسعودية)
   - **Root Directory**: `bg-removal-service` ← **مهم جداً**، هذا يخلي Render يبني من هذا
     المجلد تحديداً وليس جذر المستودع كامل
   - **Runtime**: Render يكتشف تلقائياً وجود `Dockerfile` ويستخدمه — لا حاجة لأي إعداد يدوي
   - **Instance Type**: الخطة المجانية (Free) موجودة لكنها محدودة الذاكرة وتتوقف بعد فترة
     خمول (زمن "برود" ملحوظ عند أول طلب). للاستخدام الفعلي أنصح بأرخص خطة مدفوعة (Starter)
     لثبات الأداء وتفادي مشاكل الذاكرة مع نموذج الذكاء الاصطناعي — راجع أسعار Render
     الحالية بصفحة الاختيار نفسها قبل التأكيد.
5. اضغط **Create Web Service** — يبدأ البناء والنشر تلقائياً (يأخذ عدة دقائق أول مرة).

بعد انتهاء النشر، يعطيك Render رابطاً شكله تقريباً:
`https://bawabat-zara-bg-removal.onrender.com`

**أرسل لي هذا الرابط** لأربطه بلوحة التحكم ونموذج التسجيل العام.

## التأكد إن الخدمة شغالة

افتح رابط الخدمة مباشرة بالمتصفح (بدون أي مسار إضافي) — المفروض يرجع:
```json
{"status": "ok", "service": "bawabat-zara-bg-removal"}
```

## تحديث الخدمة مستقبلاً

لو احتجت تعديل `main.py` أو أي ملف هنا لاحقاً: بمجرد ما التعديل يُرفع بـ`git push` لهذا
المستودع، Render يعيد البناء والنشر **تلقائياً بلا أي أمر إضافي منك** (Auto-Deploy مفعّل
افتراضياً على فرع main) — أسهل حتى من بروكسي جيمناي اللي يحتاج نسخ ولصق يدوي بكل تحديث.
