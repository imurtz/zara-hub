# بروكسي جلب موقع الجمعية (لحل حجب مزامنة الوفيات)

**المشكلة**: استضافة awamiach.sa بدأت تحجب أي اتصال قادم من عناوين GitHub Actions تحديداً
(حيث تعمل مزامنة الوفيات) — الاتصال يُعلَّق بلا استجابة، بينما نفس الرابط يفتح طبيعياً من أي
مكان آخر. الحل: تمرير طلبات المزامنة عبر خادم على شبكة Cloudflare بدل الاتصال المباشر.

## الخطوة 1: إنشاء الـWorker

1. من لوحة Cloudflare (نفس حسابك): **Compute (Workers)** ← **Workers & Pages** ← **Create**
   ← **Create Worker** ← سمّه `zara-awamiach-proxy`.
2. افتح محرر الكود، امسح الافتراضي، الصق محتوى [`worker.js`](worker.js) كاملاً، اضغط **Deploy**.

## الخطوة 2 (موصى بها): مفتاح حماية بسيط

لمنع استخدام الرابط من أي جهة غير سكربت المزامنة:

1. من صفحة الـWorker ← **Settings** ← **Variables and Secrets** ← **Add** ← الاسم
   `PROXY_KEY` (نوعه Secret) ← القيمة: أي نص عشوائي طويل تختاره ← احفظ.
2. أرسل لي نفس القيمة (بأي طريقة تراها مناسبة، لا تلصقها هنا في المحادثة العلنية إن كانت تُشارك
   مكانها) لأضبطها كسر مطابق في GitHub.

## الخطوة 3: أرسل لي رابط الـWorker

الرابط شكله تقريباً `https://zara-awamiach-proxy.<اسم-حسابك>.workers.dev` — أضبطه كسرّ
GitHub Actions (`FETCH_PROXY_URL`) مع سر المفتاح (`FETCH_PROXY_KEY`)، ثم أشغّل مزامنة تجريبية
فوراً للتأكد أنها فعلاً تتجاوز الحجب قبل اعتمادها بالتشغيل الدوري.
