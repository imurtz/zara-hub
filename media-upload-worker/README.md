# نقل تخزين الصور من Firestore إلى Cloudflare R2

**المشكلة الحالية**: كل صورة (شخصية، شعار جامعة) مخزَّنة كنص base64 مباشرة داخل مستند
Firestore — قاعدة "المناسبات الاجتماعية" وصلت لحوالي 37 ميقابايت بسبب هذا، وتُحمَّل بالكامل
عند فتح اللوحة، وهذا سبب التأخر.

**الحل**: الصور تُرفع لحاوية تخزين ملفات (R2) وتُخزَّن رابطها فقط (نص قصير) بالسجل بدل الصورة
نفسها بالكامل.

## الخطوة 1: إنشاء حاوية R2 (من لوحة Cloudflare نفسها، نفس حسابك)

1. من القائمة الجانبية بلوحة Cloudflare: **Storage & Databases** ← **R2 Object Storage**.
2. **Create bucket** ← سمّها `zara-media` ← أنشئها (المنطقة الافتراضية تكفي).

## الخطوة 2: ربط نطاق فرعي للحاوية (يخليها تُقرأ عبر رابط ثابت مثل صور موقعك)

1. من صفحة الحاوية `zara-media` ← تبويب **Settings** ← قسم **Public access** ← **Custom Domains**.
2. **Connect Domain** ← اكتب: `media.gzara.org`
3. يضيف Cloudflare سجل DNS تلقائياً بما إن `gzara.org` أصلاً زون بنفس حسابك — انتظر دقيقة
   لين يصير الحالة "Active".

## الخطوة 3: تفعيل CORS على الحاوية (ضروري — بدونها الصور تفشل بمولّد التصاميم)

1. بنفس صفحة **Settings** ← قسم **CORS Policy** ← **Add CORS policy**.
2. الصق هذا بالضبط:
```json
[
  {
    "AllowedOrigins": ["https://gzara.org", "https://imurtz.github.io"],
    "AllowedMethods": ["GET"],
    "AllowedHeaders": ["*"]
  }
]
```
3. احفظ.

## الخطوة 4: إنشاء Worker الرفع (نفس أسلوب بروكسي جيمناي — نسخ ولصق)

1. **Compute (Workers)** ← **Workers & Pages** ← **Create** ← **Create Worker** ← سمّه
   `zara-media-upload`.
2. افتح محرر الكود، امسح الافتراضي، الصق محتوى [`worker.js`](worker.js) كاملاً، اضغط **Deploy**.

## الخطوة 5: ربط الحاوية بالـWorker (Binding — بنفس أسلوب ربط Images بخدمة إزالة الخلفية)

1. من صفحة الـWorker ← **Settings** ← **Bindings** ← **Add Binding** ← اختر نوع **R2 Bucket**.
2. اسم المتغيّر (Variable name): اكتب بالضبط `BUCKET`
3. الحاوية (Bucket): اختر `zara-media`.
4. احفظ.

## الخطوة 6: أرسل لي رابط الـWorker

الرابط شكله تقريباً `https://zara-media-upload.<اسم-حسابك>.workers.dev` — أربطه بالكود وأختبره
فعلياً (رفع صورة حقيقية، تأكيد الرابط الناتج يفتح ويُعرض صح) قبل ما أبدأ ترحيل الـ661 سجل
الحالية.

## بعد الربط والاختبار

سأشغّل سكربت ترحيل يقرأ كل سجل حالي فيه صورة base64، يرفعها لـR2 عبر نفس الآلية، ويحدّث
السجل ليخزّن الرابط بدلها — سجلاً سجلاً، مع تقرير نهائي بعدد ما نجح/فشل، **قبل** حذف أي بيانات
قديمة.
